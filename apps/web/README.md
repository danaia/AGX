# ANGI Web

A WPE WebKit application embedded in ANGI's native desktop. Open **Web** from **Apps** (Super+Space). Native selection menus and JavaScript alert/confirm/prompt dialogs are supported. Downloads are supported (see below). File picking, a download manager and browser extensions are outside the current host. The window uses the same tiling, floating, resizing, fullscreen and header-collapse controls as other apps. Ctrl+L selects the address; Ctrl+R reloads.

The pinned engine is WPE WebKit 2.54.2, using the stable WPEPlatform API directly. Cog and a separate Wayland compositor are not required. The DRM platform is available in the engine build, but the embedded app uses a custom offscreen view backed by WPE's headless EGL/GBM display. Taking over the entire DRM display would bypass the desktop window manager.

`host.c` owns WebKit lifecycle and sandboxed user data; `tabs.c` owns independent views, active-tab selection and tab status; `platform.c` owns display/view integration and frame delivery; `protocol.c` owns bounded local IPC and WPE input events; `dialogs.c` owns form menus, script dialogs and routing user-opened links into the same window; `downloads.c` saves downloads to `~/Downloads`; `storage.c` keeps page data, HTTP cache, font cache and shader cache off the small SD root. The GUI's `src/browser/` owns process lifetime, chrome, input translation and presentation. No web engine is loaded into the GUI process. Closing Web honors unsaved-page confirmation, allows a brief graceful shutdown, then kills a stuck process group; hiding/collapsing unmaps its view. Hidden sites may still run JavaScript/network activity according to WebKit's background policies.

On the native HDMI desktop, WPE passes single-plane DMA-BUF frames to the GUI over a private descriptor socket. The GUI imports each buffer as an EGLImage and copies it on the GPU into two reusable Slint textures. This removes CPU pixel readback, channel conversion, shared-memory pixel copies and texture uploads from native presentation. It retains one GPU-to-GPU copy so the displayed texture remains stable when WebKit reuses its source; this is not a zero-copy path. Frame arrival schedules redraw immediately. Exported native completion fences are waited on by one sleeping worker, allowing source buffers to be acknowledged without blocking the UI thread. Drivers without native fence export use a bounded EGL fence wait instead.

Software/VNC desktops and unsupported GPU imports retain the CPU bridge: WPE renders offscreen, converts BGRA to opaque RGBA into a sealed-size memfd, and the reader wakes the desktop when a frame arrives. GPU import failures request a CPU republish of the still-owned frame. Both paths keep one source frame in flight and at most one pending engine buffer. Geometry updates are coalesced to ten per second during continuous resizing, and the viewport is capped at 4096×2160. Hidden/collapsed views are unmapped; closing Web releases its textures and ends its engine processes. Page timers and background network activity follow WebKit policy.

`AGX_WEB_GPU=off` selects CPU presentation for comparison; `AGX_WEB_TRACE=1` logs presentation rate and GPU submission time. These diagnostics are off by default. `AGX_WEB_GPU=probe-fallback` deliberately requests CPU fallback after the first GPU frame for integration testing. Native tests can force an unused DRM connector temporarily without an HDMI cable; restore its sysfs status to `detect` afterward so automatic display selection continues to work.

This build includes JavaScript, CSS, Canvas and WebGL, subject to the installed Mesa driver. Multimedia (video, audio, WebRTC), WebDriver, spellchecking and speech synthesis are disabled at build time to reduce dependencies. The host disables developer extras and removes inspector-server environment overrides. Web content runs as the signed-in user with WebKit's bubblewrap sandbox enabled. The host refuses root. Normal HTTPS certificate verification remains enabled; on the appliance, cookies and caches live in `/var/lib/agx-data/agx-web-users/<uid>` with mode 0700. The greeter prepares this private store before dropping privileges. Other development hosts use XDG directories. Shader cache defaults to a 64 MiB limit. There is no privileged JavaScript bridge or remote debugging listener.

**Downloads.** Links that cannot be displayed, `download` links and blob/data downloads are saved to `~/Downloads`. The SD root is small, so on the appliance Web creates `~/Downloads` at startup as a link to a private (0700) `downloads` folder in the signed-in user's NVMe store, `/var/lib/agx-data/agx-web-users/<uid>/downloads`; an existing `~/Downloads` folder or link is used as-is, and development hosts get a plain `~/Downloads` folder. `AGX_WEB_DOWNLOADS=/absolute/path` overrides the destination for testing. Files lists Downloads in its sidebar, and the overview's NVMe file map includes the folder so large downloads can be deleted there. Names are reduced to a safe single filename and never overwrite: a second `report.pdf` becomes `report (1).pdf`. A download is refused up front when its announced size would leave under 64 MiB free. A bar at the bottom of the page reports start, completion, cancellation and failure, and dismisses itself after eight seconds or with ×. The host and GUI must be updated together: the GUI treats the download notice message as part of the private protocol.

Local `.html`/`.htm` pages (from `open FILE` in a terminal) are loaded by the host as `text/html` bytes with their own `file://` address as the base, because the image's MIME database would otherwise make WebKit parse them as XHTML; `make deploy-web-host` rebuilds and installs only the host. Servers on this device (`localhost`, `127.x.x.x`, `[::1]`) are ordinary `http://` pages, and bare names of that kind typed in the address bar default to `http://`.

After sign-in, ANGI prepares the Web host in the background. Google loads when Web first becomes visible on workspace 4. WebKit uses its browser cache model for repeat visits. **+** opens another tab and **×** closes the active tab. **Ctrl+T**, **Ctrl+W**, and **Ctrl+Tab** open, close, and switch tabs. Each tab keeps its own page and history. **Alt+Left/Right** navigates history; the page viewport follows the content area rather than stretching a fixed-resolution image.

On Pi 4 / 400, Web uses the signed-in account’s XDG data and cache directories when the system runs from microSD alone. Downloads use the account’s `~/Downloads` folder. A mounted data volume takes precedence and uses the same private per-account storage as on Pi 5.

The appliance bubblewrap patch retains its existing safe-open fallback when the external toolchain lacks the `openat2` syscall definition, even with a recent target kernel. It does not disable sandboxing.

Build with `scripts/build-web.sh` (`WEBKIT_BUILD_JOBS=3` by default to bound build memory). It builds the engine, native dependencies and `.cache/agx-web/agx-web`. The engine runtime is much larger than the embedding host. `make deploy-web` builds the GUI and engine, installs the runtime on NVMe, and restarts the GUI to expose the launcher entry. Sign in again afterward. This leaves the running appliance’s small SD root intact. New full images use a 512 MiB root partition to include the selected browser package. Never replace `/lib`, `/lib64`, libc or the active loader when installing the runtime on a running appliance.

`tests/smoke.html` exercises viewport resizing, typing, pointer clicks, scrolling, Canvas and WebGL. `tests/scroll.html` continuously scrolls a grid of text, gradients and shadows for CPU/GPU comparison. These are manual/integration fixtures, not part of the start page. Disconnect VNC viewers during native timing: framebuffer capture adds overhead. Measure the same display mode and viewport, discard startup samples, and compare `AGX_WEB_GPU=off` against the default with `AGX_WEB_TRACE=1`. Frame rate depends on page complexity, resolution and refresh rate.

For incremental development, rebuild the local-source host with Buildroot’s `agx-web-rebuild` target after changing its C sources. `AGX_WEB_HOST` overrides the embedding-host path for desktop integration tests.
