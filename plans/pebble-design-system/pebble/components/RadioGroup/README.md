# RadioGroup

Tiny inset rings laid out in a wrapping row, the selected one holding a `graphite` dot — straight from the reference's Category card.

Rendered as a `<fieldset>` with the `label` as its legend, so the group is announced. Ring edge is `line-strong` (3:1) so unselected options stay visible. Use for one choice out of 2–8; more than that, use Select.
