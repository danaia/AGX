# IconButton

A round (or `square`) raised button holding one icon; `active` presses it in for toggles.

`label` is required — it becomes the accessible name. Use for toolbars, card corners and toggles (like, mute, view). Icons are `ink-muted` at rest and `ink` on hover or when active. Sizes `sm` 36 / `md` 44 / `lg` 56px.
