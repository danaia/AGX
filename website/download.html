Questions

Do I need to build anything?

No. Your agent downloads a ready-made image and writes it. Building ANGI from source is only for people changing the operating system itself; the steps live in the repository.

Which image do I pick for a Pi 400?

The Pi 4 / 400 image. Both use the same board support.

Does the image include my passwords or keys?

No. Images are generic. You create your own administrator account and join Wi-Fi in your browser on first start.

Will writing the image erase my card?

Yes. Your agent shows you the card first and erases nothing until you type erase followed by the card's exact device path.

How does the agent know the image is genuine?

Each image is published with a .sha256 file next to it. The agent compares the download against it and stops if they differ.
