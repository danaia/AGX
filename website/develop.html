Two ways to build.
Both live.

ANGI ships with the bare minimum. The rest is yours to craft, on ANGI itself or from the computer next to it. Over USB-C or Ethernet, your changes land on the running system without a reflash or a reboot.

On the device

Use ANGI's desktop on a monitor, or its dashboard over SSH. The agents run on the board and compile natively.

  • Agent Angi: chat, hand it a project folder, or let it change the OS
  • agent angi starts an orchestrator, builder and tester from the terminal
  • Monaco code editor, native terminal, WebKit browser and files with undo
  • Changes to the OS install with the same live reload and rollback guard

From your computer

Keep your own editor, agents and tools. Your computer talks to ANGI over a direct cable and updates it while it runs.

  • One USB-C cable for power and network, or direct Ethernet
  • Hot reload: a deployed desktop loads into the running session
  • Rollback guard: a watchdog restores the previous release if needed
  • Control everything with agx commands and --json output

A private cable between two computers.

The cable has no internet gateway, so your computer keeps its own connection and ANGI reaches the web over Wi-Fi.

See it live

The desktop reloads in place. If the new release does not stay up, the previous one comes back.

From your checkout of the repository 
# Point the deploy at ANGI: USB-C 10.77.0.2 or Ethernet 10.78.0.2
export AGX_SSH_HOST=root@10.77.0.2
export AGX_SSH_KEY=~/.ssh/id_ed25519

make deploy-gui       # desktop, reloads in the running session
make deploy-tui       # terminal dashboard
make deploy-network   # network services

Deploys sign in with an SSH key. See the repository docs for the toolchain and every deploy target.
