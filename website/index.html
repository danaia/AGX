Two ways to build

Code on the device,
or from your computer.

Use ANGI's own desktop and agents, or keep your editor and tools and update ANGI from your computer while it runs.

On the device

Everything you need runs on ANGI itself. Describe a task and let the agents build it, or write the code yourself.

  • Run agent angi: an orchestrator, builder and tester work on the board
  • Code editor, terminal, browser and file manager built in
  • One-click apps from the Apps tab, installed per account

From your computer

Connect over USB-C or Ethernet and push updates to the running system from another computer. No reflash, no reboot.

  • Hot reload: a new release loads into the running desktop
  • Rollback guard: the previous release returns if the new one fails
  • Every agx command speaks --json over SSH

What's inside

Small enough for a Pi Zero.
Complete enough to ship from.

No Debian, Ubuntu, Arch or Fedora underneath, and no package manager to inherit. ANGI is assembled from source and written in Rust from init to desktop.

Rustinit, services, CLI and desktop

Agent Angi

Chat, hand it a project, or point it at the OS itself.

Code editor

Monaco, the editor behind VS Code, with before-and-after review.

Web browser

WebKit-based, with tabs, downloads and WebGL.

Terminal

Native tabs and windows, tuned for agent output.

Tiling desktop

Keyboard-first tiling, plus a full dashboard over SSH.

Files with undo

Real undo, a proper Trash, and serve-a-folder in one click.

Wi-Fi and Tailscale

Join Wi-Fi from the dashboard; reach LM Studio privately.

Scriptable

Status, services, logs and power, each with JSON output.
