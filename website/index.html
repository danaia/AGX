Differentiators

      
Everything a person needs. Nothing an agent has to fight.

      
Most operating systems are made for people and adapted for agents later. ANGI starts from the other end.

    

    

      
Tiny by design
About 93 MB of files. A 0.5 MB init. Boots to SSH in roughly 2.5 seconds, and idles at about 120 MB of RAM.

      
Not a distribution
No package manager, no release cycle, no legacy to stay compatible with. Assembled from source with Buildroot, so the image holds only what ANGI asks for.

      
Swarm generated
Coding agents wrote the system and keep rewriting it. Three cooperating agents plan, build and test, and the OS itself is in scope.

      
Rust, top to bottom
PID 1, the service supervisor, network and account services, the CLI, the terminal dashboard and the desktop. About 11,000 lines in one workspace.

      
Everything is scriptable
Status, services, logs, Wi-Fi, accounts and power each have an agx command with --json output. What an agent can do, you can do.

      
Fully inspectable
One repository holds boot to dashboard. An agent can read it, change it, rebuild it, flash it and verify the result.

      
A desktop that respects your hands
Hyprland-style tiling and Omarchy's keyboard-first chords: Super + arrows to move focus, Super + Q to close, Super + 1–5 for workspaces. Borrowed experience, not a borrowed base system.

      
A fraction of the cost
Lightweight, low-cost models, each given only the intelligence a task needs. Small hardware, small bills.

    

  






  

    

      
Just the essentials

      
The bare minimum, built in.
Everything else on demand.

      
ANGI ships the few things a builder reaches for every day, in about 93 MB. The rest is a click away and stays out of the image.

    


    

      
A real web browser
Built on WebKit (WPE). Tabs, downloads, bookmark import from Chrome, JavaScript, Canvas and WebGL. Preview what you build without leaving the machine.

      
Agent Angi, in conversation
Chat with Angi, or hand it a project or the OS itself. Three modes, one prompt, with history you can reopen and review.

      
A serious code editor
Review every agent change in Monaco, the editor engine behind VS Code, with before-and-after tiles. Neovim, Helix and micro install in one click.

      
Native terminal
Real tabs and windows on the desktop, tuned for agent output. Your tools in your PATH, installed per account.

      
Files that can undo
A fast file manager with real undo and a proper Trash. Right-click a folder to serve it and open it in the browser at once.

      
Bluetooth Preview
Find, pair and connect devices from Settings, the CLI or an agent, through one policy-checked service. Hardware testing is still under way.

      
Wi-Fi and private networking
Join Wi-Fi from the dashboard, and reach LM Studio on your own computer over Tailscale without opening the Pi to the internet.

      
A tiling desktop and a terminal dashboard
Omarchy-style tiling on the Pi's display, plus a full dashboard over SSH. Services, logs, storage heat maps and updates are one keypress away.

One board

01 / THE BOARD

          
A credit-card-sized computer.

          
A Raspberry Pi 5 is the machine ANGI is made for. No workstation, no rack, no cloud account. One affordable board, a power cable, and a network cable.

        

        

          
02 / THE SYSTEM

          
A whole swarm, on a 4 GB board.

          
ANGI is about 93 MB of files, boots to SSH in about 2.5 seconds, and idles at roughly 120 MB of RAM. On a 4 GB Pi that leaves about 97% of memory for the agents. The system is built so an entire swarm fits.

          
~120 MBidle RAM, measured on a 16 GB Pi. The swarm-on-4 GB fit is our design target, not yet benchmarked, and depends on model connectivity: OpenAI, Claude or LM Studio.

        

        

          
03 / THE SWARM

          
The agents work on the board itself.

          
An orchestrator, a builder and a tester compile natively on the Pi, with source, tools and caches on NVMe. The machine that runs the system is the machine that builds it.

        

        

          
04 / THE OUTPUT

          
Enterprise-grade software, shipped from one Pi.

          
Everything the swarm produces leaves over the network, scriptable and verifiable. That is the claim ANGI exists to prove: serious software does not need serious hardware.

        

      

    

  









  

    

      
Independent

      
No distribution underneath.

      
ANGI is assembled from source. It runs the Linux kernel and a few small, well-known components, then owns everything above them, which is where agents do their work.

      
    
        
  • Linux kernel trimmed for the Pi 5, with the Pi's own firmware bootloader.
    • 
        
  • Tiny, proven parts: BusyBox, Dropbear, wpa_supplicant, Mesa.
    • 
        
  • Everything else is ANGI, in Rust, readable by an agent.

What the swarm depends on

      
The agents live on the Pi.
The thinking happens elsewhere.

      
That is why a swarm can be light enough for a small board. It also means the swarm needs a connection to a model: OpenAI, Claude, or LM Studio running on your own computer. Without one, there is nothing to think with.

    

    

      
      
No connection, no swarm. Cloud models need the Pi's Wi-Fi to reach the internet. LM Studio needs the Pi and your computer on the same private Tailscale network. Pick whichever fits your privacy and cost.

Your coding agent
is the installer.

      
One prompt. Your agent builds ANGI, watches the build and keeps you posted, and puts it on an SD card on your computer. It then tells you how to move the card into the Pi, and hands you a short second prompt to get the whole system ready.

      
Any agent harness or IDE works, as long as it can run commands: Codex, Claude Code, Cursor, OpenCode, Hermes and others. A chat in a browser tab cannot do the install.

01 / CARD FIRST

          
Set up the card on your computer first.

          
Pick your computer: a Pi Zero 2 W, Pi 4, Pi 5, or an ARM or x86 desktop. Put a microSD card in a card reader on your computer. The Pi stays off, with no card in it.

        

        

          
02 / THE PROMPT

          
Give your agent the prompt.

          
It asks which computer you have, fetches ANGI and builds the right image for it with your SSH key. The build takes about 1 to 3 hours; your agent watches it and tells you how it is going.

        

        

          
03 / FORMAT THE CARD

          
Erase and write it here, after you say yes.

          
The agent shows you the card and waits for you to type its path. Then it wipes the old partitions, writes the image and checks every byte. No ISO, no installer, no wizard, and never inside the Pi.

        

        

          
04 / MOVE THE CARD

          
Now put the finished card in the Pi.

          
This is the only physical step. Take the card out of the reader, slide it into the Pi, and power the Pi on.

        

        

          
05 / CONNECT

          
Connect Ethernet or USB-C.

          
Connect the Pi to your computer and paste the second prompt your agent gave you into a new chat. Your agent connects over the cable and checks that ANGI is running.

          
agx statusover Ethernet or USB-C

        

        

          
06 / WI-FI

          
Join Wi-Fi. This is the key step.

          
Your agent connects ANGI to your Wi-Fi and confirms it can reach the web. You type your password once, privately. After that, ANGI is online on its own and keeps reconnecting after a reboot.

          
agx wifi checkDNS and HTTPS, verified

        

        

          
07 / EXTEND, LIVE

          
Change the OS while it runs.

          
Build and install new software through the same link. A deploy loads the new release into the running desktop. It keeps the same process and needs no reboot, and a watchdog restores the previous release if the new one does not stay up.

          
make deploy-guino reflash, no reboot
